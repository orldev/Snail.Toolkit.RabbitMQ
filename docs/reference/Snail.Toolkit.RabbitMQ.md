### class RabbitQueueBindingDeclaration

Represents the declaration of a binding between a RabbitMQ queue and exchange.

| Member | Summary |
| --- | --- |
| `IDictionary<string, object?> Arguments { get; }` | Gets additional binding arguments that can be used to configure advanced binding features. |

| `RabbitQueueBindingDeclaration(RabbitExchangeDeclaration exchangeDeclaration)` | Represents the declaration of a binding between a RabbitMQ queue and exchange. |
| `bool Deleted { get; set; }` | Gets or sets a value indicating whether this binding should be removed rather than created. |

### class RabbitQueueDeclaration

Represents the declaration and configuration of a RabbitMQ queue.

| Member | Summary |
| --- | --- |
| `IDictionary<string, object?> Arguments { get; }` | Gets additional queue arguments that can be used to configure advanced queue features. |
| `IReadOnlyList<RabbitQueueBindingDeclaration> BindingDeclarations { get; }` | Gets the collection of binding declarations that define how this queue is bound to exchanges. |
| `RabbitConnectionDeclaration ConnectionDeclaration { get; }` | Gets the connection declaration used to connect to the RabbitMQ server. |
| `RabbitQueueDeclaration(RabbitConnectionDeclaration connectionDeclaration, string name)` | Represents the declaration and configuration of a RabbitMQ queue. |
| `RabbitQueueDeclaration? ParkingQueue { get; }` | Gets the parking queue declaration where messages land once the retry budget is exhausted. |
| `RabbitQueueDeclaration? RetryQueue { get; }` | Gets the companion retry queue declaration, if retry with backoff is configured. |
| `bool AutoDelete { get; set; }` | Gets or sets a value indicating whether the queue should be automatically deleted when no longer in use. |
| `bool Deleted { get; set; }` | Gets or sets a value indicating whether the queue should be deleted rather than declared. |
| `bool Durable { get; set; }` | Gets or sets a value indicating whether the queue survives server restarts. |
| `bool EmptyOnly { get; set; }` | Gets or sets a value indicating whether the queue should only be deleted if it's empty. |
| `bool Exclusive { get; set; }` | Gets or sets a value indicating whether the queue should be exclusive to this connection. |
| `bool NoWait { get; set; }` | Gets or sets a value indicating whether the server should respond without waiting for queue creation. |
| `bool UnusedOnly { get; set; }` | Gets or sets a value indicating whether the queue should only be deleted if it's unused. |
| `int MaxAttempts { get; }` | Gets the maximum number of processing attempts per message before it is dropped or parked. |
| `string Name { get; }` | Gets the name of the queue. |
